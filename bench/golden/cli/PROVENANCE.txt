These are NOT asserted byte for byte by bench/equivalence.sh, and that is
deliberate: clap and argparse lay help text out differently, nothing downstream
parses it, and the isONcorrect port made the same call. What the harness does
assert is exit codes, the reference's own diagnostics verbatim, the stray stdout
prints, and the full resolved argument set via the `ARGS Namespace(...)` line.

These files are here so that a change to a flag's name, default or help text is
visible on inspection, and so the two entry points' surfaces can be diffed
against each other. Two things worth knowing when reading them:

    2*k *before* noticing there were no arguments, so it announces the
    adjustment and then prints help.
  * isONform_parallel.noargs.stdout begins with `1`. That is
    `print(len(sys.argv))` at isONform_parallel:370, a debug leftover that is
    nonetheless observable. PORTING.md finding 4.
